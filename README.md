# ☕ Coffee Shop Sales Analysis

A business-focused sales analytics project using **MySQL, SQL, Power BI, and DAX** to analyze coffee shop transaction data and identify patterns in sales performance, customer purchasing behavior, product performance, and time-based trends.

---

## 📌 Project Overview

This project analyzes coffee shop transaction data to transform raw sales records into actionable business insights.

The analysis was performed using **MySQL and SQL** for data preparation and exploration, followed by **Power BI and DAX** for interactive business intelligence and visualization.

The goal is not only to report sales numbers, but to understand:

- What products generate the most revenue?
- When are sales highest?
- Which products and categories perform poorly?
- How does sales performance change over time?
- What patterns can help improve business decisions?

---

## 🎯 Business Problem

A coffee shop generates a large number of daily transactions, but raw transaction data alone does not provide an easy way to understand business performance.

The business needs a reporting solution that can answer questions such as:

1. What is the overall sales performance?
2. Which products contribute the most to revenue?
3. Which product categories perform best?
4. What are the busiest days and hours?
5. How does sales performance vary across months?
6. Which products may require additional attention?
7. What patterns can be used to support better business decisions?

This project addresses these questions through SQL analysis and an interactive Power BI dashboard.

---

## 📊 Dataset

The dataset contains coffee shop transaction-level sales data.

Key fields include:

- Transaction Date
- Transaction Time
- Product
- Product Category
- Quantity Sold
- Unit Price
- Revenue / Sales Amount
- Store-related or transaction attributes where available

Each row represents a sales transaction or transaction-level product record.
